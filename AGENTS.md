# AGENTS.md

## Project overview
This repo is for designing and eventually building a personal continuity engine.

## Working rules
- Start docs-first.
- Prefer clarity over premature implementation.
- Keep the product grounded in real Brendan-first use.
- Avoid generic productivity language when more precise language exists.
- Do not broaden scope into team PM, therapy, or generic note-taking.
- Treat re-entry, continuity, and trustworthy delegation as core concepts.

## Delivery discipline
- Small, reviewable changes.
- Document major product decisions.
- Keep open questions explicit.
- Prefer the simplest architecture that preserves local trust and future shareability.
