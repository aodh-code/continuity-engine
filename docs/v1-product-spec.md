# V1 Product Spec

## Product goal
Help a high-agency person recover continuity across days, moods, projects, and interruptions by giving them one trustworthy surface for what matters, what moved, what drifted, what to do next, and what can be delegated.

## V1 promise
When I open this, I can re-enter my real life and work quickly.

## Core surfaces
- Today
- Continuity
- Projects
- Memory / context
- Reflection

## Key workflows
- Morning re-entry
- After drift
- Nightly close
- Project focus

## Success criteria
1. The user feels orientation, not admin fatigue.
2. The system helps resume meaningful work faster.
3. Drift and forgotten commitments are reduced.
4. Delegation becomes safer because context is visible.
5. The system feels psychologically true, not cosmetically productive.
